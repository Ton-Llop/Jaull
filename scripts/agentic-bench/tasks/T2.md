# Task T2: Vulkan devices under WSL2 cannot be told apart

Under WSL2, Vulkan goes through Mesa's Dozen layer, and llama.cpp reports device names that wrap the
real card name in a trailing parenthesis, for example:

    Microsoft Direct3D12 (Intel(R) Arc(TM) Pro B60 Graphics)
    Microsoft Direct3D12 (AMD Radeon(TM) Graphics)

Jaull matches the accelerator the user selected against the devices the runtime reports
(`src/jaull/runtime/device_matching.py`). Today it removes one trailing annotation from every name
before comparing, so both Dozen devices become "Microsoft Direct3D12" and neither can be chosen.

Removing a trailing annotation is still needed when only one of the two names carries it (for
example `Intel(R) Arc(TM) Pro B60 Graphics` against `Intel(R) Arc(TM) Pro B60 Graphics (BMG G21)`).
When both names carry one, it is part of the device's identity. A near name (`RTX 2060` against
`RTX 2060 SUPER`) must still be a different device.

The new test below reproduces the problem and currently fails:

    uv run pytest tests/test_runtime_device_matching.py

Make it pass without breaking the rest of the test suite (`uv run pytest`).

Rules: do not modify, add or delete anything under `tests/`. Change only the application code.
