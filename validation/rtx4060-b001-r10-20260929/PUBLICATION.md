# Public anonymized evidence

Public anonymized derivative: account, hostname and user-directory strings replaced. Measurements, artifact/runtime binary digests, IDs and observation timestamps are unchanged. Original bytes are retained privately; this is not the byte-exact original export.

See [the publication ledger](../public-anonymization.json) for original and derivative file digests. Paths are placeholders, not commands to run on the collection machine. A valid public bundle certifies its derivative bytes only. Historically invalid bundles remain invalid; their manifests were not repaired.
